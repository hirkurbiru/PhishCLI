# Contributing to PhishCLI

Thank you for your interest in contributing to PhishCLI.

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Improving documentation
- Suggesting enhancements
- Submitting pull requests

---

## Development Setup

1. Fork the repository.

2. Clone your fork.

```bash
git clone https://github.com/hirkurbiru/PhishCLI.git
```

3. Create a virtual environment.

```bash
python -m venv .venv
```

4. Activate the environment.

Windows

```bash
.venv\Scripts\activate
```

Linux

```bash
source .venv/bin/activate
```

5. Install dependencies.

```bash
pip install -r requirements.txt
```

---

## Coding Guidelines

- Follow PEP 8.
- Keep functions focused and modular.
- Add docstrings for new modules and functions.
- Maintain consistent formatting.

---

## Pull Requests

Before submitting a pull request:

- Ensure the project runs successfully.
- Update documentation if required.
- Verify your changes do not introduce regressions.

---

## Code of Conduct

Please be respectful and constructive when participating in discussions or contributing to the project.

---

## Questions

If you have questions or suggestions, please open a GitHub Issue.
